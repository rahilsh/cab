# Governance

Cab Marketplace currently uses a maintainer-led governance model.

Maintainers review contributions, set release scope, resolve architectural decisions, and enforce
the Code of Conduct. Significant API, persistence, security, or module-boundary changes require an
architecture decision record under `docs/adr`.

As the contributor community grows, maintainership may be granted based on sustained technical
contributions, constructive reviews, operational responsibility, and adherence to project policy.
Governance changes are proposed and reviewed through pull requests to this file.
